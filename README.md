# Sard Story Books – kickoff pack

1. Unzip this folder into the root of your repo (you get `your-repo/sard-kickoff/`).
2. Open Claude Code in the repo and paste the whole of `prompts/01_SETUP_PROMPT.md`.
3. Fill `test-data/` (see `test-data/README.md`) and create `.env` from `.env.example`.
4. Paste the whole of `prompts/02_M1_PROMPT.md` to start milestone M1.
